# Задача 2. Оценка экономической эффективности внедрения облачной CRM

## Условие

Компания «ТехноПром» рассматривает вопрос о внедрении облачной CRM-системы для отдела продаж.
Необходимо оценить экономическую эффективность проекта по показателям NPV, простого срока окупаемости и ROI.

---

## Исходные данные

**Исходные данные по проекту:**

| Параметр ($обозначение$), единица измерения | Значение |
|---|---|
| Количество менеджеров в отделе продаж ($n$), чел. | $15$ |
| Средняя зарплата менеджера ($S$), руб./мес. | $120\,000$ |
| Экономия времени на рутинных операциях ($k$), % | $20$ |
| Доля рабочего времени на рутинные операции без CRM ($u$), % | $30$ |
| Годовой рост продаж ($g$), % | $8$ |
| Текущий годовой оборот отдела продаж ($Q_0$), руб. | $72\,000\,000$ |
| Стоимость облачной CRM на пользователя в год ($c$), руб. | $24\,000$ |
| Время на обучение ($m$), мес. | $1$ |
| Горизонт оценки ($T$), лет | $3$ |
| Ставка дисконтирования ($r$), % | $12$ |
| Налог на прибыль ($h$), % | $20$ |

---

## Задание

1. **Прямой эффект:** экономия на зарплате за счёт автоматизации (годовая); дополнительный доход от роста продаж.
2. **Затраты:** стоимость лицензий за $3$ года; потери от снижения производительности в первый месяц обучения.
3. **Финансовые показатели:** прирост чистой прибыли по годам (с учётом налога); NPV (при $r = 12\%$); простой срок окупаемости; ROI.
4. **Нематериальные эффекты:** выгоды CRM и влияние парадокса производительности Солоу.
