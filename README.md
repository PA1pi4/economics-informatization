# Экономика информатизации – практические решения

Две практические задачи по курсу **«Экономика информатизации»** (Курс 4, семестр 1).
Каждая задача – отдельная папка с условием, кодом и развёрнутым решением.

## Содержание

| # | Задача | Папка | Инструменты |
|---|--------|-------|-------------|
| 1 | Оценка влияния автоматизации (ERP) на производительность труда | [`task1-erp-productivity`](./task1-erp-productivity) | `numpy`, `pandas`, `scipy`, `matplotlib` |
| 2 | Оценка экономической эффективности внедрения облачной CRM | [`task2-crm-efficiency`](./task2-crm-efficiency) | `numpy`, `pandas` |

## Структура

```
.
├── README.md
├── requirements.txt
├── run_all.py                     # запуск обоих решений одной командой
├── .gitignore
├── task1-erp-productivity/
│   ├── README.md                  # развёрнутое решение
│   ├── task.md                    # условие задачи
│   ├── solution_task1.py          # код (генерирует диаграмму)
│   └── expected_output.txt        # ожидаемый вывод программы
└── task2-crm-efficiency/
    ├── README.md                  # развёрнутое решение
    ├── task.md                    # условие задачи
    ├── solution_task2.py          # код
    └── expected_output.txt        # ожидаемый вывод программы
```

> `illustration.png` **не хранится в репозитории** — диаграмма автоматически генерируется скриптом `solution_task1.py` при каждом запуске (рядом со скриптом). Это исключает рассинхронизацию картинки и данных.

## Быстрый старт

```bash
# 1. Установить зависимости
pip install -r requirements.txt

# 2а. Запустить оба решения сразу
python run_all.py

# 2б. Или по отдельности
python task1-erp-productivity/solution_task1.py
python task2-crm-efficiency/solution_task2.py
```

Запуск `solution_task1.py` дополнительно создаёт рядом со скриптом файл `illustration.png` со столбчатой диаграммой «до/после» по отделам.
В окно график не выводится — это сделано, чтобы `run_all.py` последовательно выполнял оба решения без блокировки.

## Краткие результаты

**Задача 1.** Средняя выработка выросла с 129.00 до 150.00 тыс. руб./чел. (+16.28%).
Парный t-критерий: t = 6.3317, p-value = 0.0032 → рост **статистически значим**.

**Задача 2.** NPV (r = 12%) ≈ 12 420 066 руб., срок окупаемости – в течение 1-го года, ROI ≈ 547.4%.
Проект **экономически эффективен**.
